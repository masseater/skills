# sheet

引数: `$ARGUMENTS`

作品のフォルダは `art/<作品名>/` で、この段階は `core.md` と `definition.md` を読み、`sheets.md` に追記する。

## なぜこのスキルが必要で、どのような状態を目指すべきか

このスキルが必要な理由は、参照用の図は後で人や AI がそれだけを見て作るためにあるのに、生成に任せると見栄えのする 1 枚になるからだ。ビューごとに高さや比率がずれ、遠近や影で形が読めなくなる。用途はまだ決まっていないので、特定の用途に合わせた図にすると、別の用途で作り直しになる。

このスキルが目指す状態は、定義の姿を、どの角度、どの状態でも同じものとして読める図の組がそろっている状態である。

## 図の組

`core.md` の対象の種類で決める。持ち主が欲しい図を挙げたときはそれを作る。

| 対象 | 図 |
| --- | --- |
| キャラクター | 全身の正面・側面・背面。表情（通常、まばたき、目を閉じた笑顔、喜、怒、哀、驚）。口形（あ、い、う、え、お）。ビューで隠れる細部（髪の分け目、持ち物、靴底など） |
| 小物 | 正面・側面・上面・背面。細部の拡大。素材の注記。手や人と並べた大きさ |
| 背景・場所 | 上から見た配置図。主な視点からの眺め。時間帯と光の違い |
| イラスト | 構図のサムネイル。明暗だけの習作。色の計画 |
| 世界観 | モチーフ集。使う形と使わない形。共通パレット |

## プロンプトの書き方

- `definition.md` の固定ブロックを一字一句そのまま貼り、確定画像を参照画像として添付するよう書く。
- 遠近のない正投影、影の少ない平らな光、無地の背景、全ビュー同じ縮尺にする。形を読む図なので、見栄えの演出は形を隠す。
- ビューを並べる図では、高さの基準線（頂点、目、あご、肩、腰、膝、足元など、対象に合わせる）を全ビューで水平にそろえる。同じ点が同じ高さにないと、図から形を起こせない。
- キャラクターの全身は、腕と脚が胴に重ならない、表情のない立ち姿にする。輪郭が重なると、胴の形が読めない。
- 各パネルにラベル（front、side、back、a、i、u、e、o など）を付ける。
- 差分（表情、口形、時間帯）は、変える部分以外を確定画像と同じに保つよう書く。
- プロンプトは 1 つずつコードフェンスに入れ、出したプロンプトと生成した画像のパスを `sheets.md` に追記する。
