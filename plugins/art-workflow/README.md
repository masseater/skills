# art-workflow

キャラクター、小物、背景、イラスト、世界観などのアート作品の姿を決めるプラグインである。参考の見た目をなぞらず、参考から核の概念だけを抜き出し、そこから姿を探って確定し、参照用の図を作る。3D、Live2D、イラストなどの用途は決めずに進め、出来た図はどの用途にも使える。画像は ChatGPT で生成し、Claude はそのプロンプトを書き、出来た画像をチェックする。生成では汎用の絵柄から抜けないときは、Claude が JavaScript で SVG を組んで描く（`sheet` の `match-style`）。

## スキル

段階の順に使う。

- `core`: 参考から、見た目を捨てて核の概念を抜き出す
- `explore`: 核から、互いに違う方向の案を並べるプロンプトを書く。選ぶか混ぜるかを繰り返す
- `lock`: 選んだ姿を、毎回同じ文面で再現できる定義にする
- `sheet`: 定義から、3面図、表情と口形の差分、配置図など、対象に合った参照用の図のプロンプトを書く
- `critique`: 生成した画像を、核と定義に照らして見て、直すプロンプトを返す。どの段階でも使う

## 作品のフォルダ

1 つの作品を、作業ディレクトリの `art/<作品名>/` に置く。

```text
art/<作品名>/
  core.md        核の概念と、捨てた見た目
  explore.md     探った案、選んだ案、却下した理由
  definition.md  確定した姿の定義
  sheets.md      参照用の図のプロンプトと、出来た画像
  images/        生成した画像
```

## インストール

`/plugin install art-workflow@masseater` でインストールする。`/art-workflow:core 作品名` から始める。
