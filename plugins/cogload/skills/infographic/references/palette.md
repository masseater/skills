# 色と形

要素を種類で分け、種類ごとに色と形を決める。見る人は色と形で「人か、システムか、データか」を先に読み、名前を読む前に図の構造をつかむ。名前は必ずその場所に書くので、凡例は要らない。見本は [palette.svg](../examples/palette.svg)。

![要素の 5 種類と外部、2 種類の線、4 つの状態の札](../examples/palette.svg)

## 種類

| 種類 | 形 | 明るい背景 | 暗い背景 | 使う場面 |
| --- | --- | --- | --- | --- |
| 人・エージェント | 両端が半円のカプセル | `#2151af` | `#3769ca` | オーナー、Claude、チーム、利用者 |
| システム | 角を大きく丸めた長方形 | `#966cd7` | `#ae84f2` | ツール、Worker、コード、処理 |
| データ・もの | 下辺が波打つ紙 | `#179a8e` | `#2da79b` | ファイル、記録、ページ、文章 |
| 量・金額 | 楕円 | `#d16022` | `#ed7940` | 費用、件数、率、基準 |
| 条件・判断 | 両端がとがったレンズ | `#942464` | `#af3e7c` | 分かれ道、規則、選択、決定 |
| 外部 | ゆがんだ雲の破線 | `#6b7785` | `#8d99a6` | 他者のサービス、まだ動いていないもの |

- 1 つの要素は 1 つの種類に入れる。迷うときは、その要素に何が起きるかで決める。人は動かし、システムは処理し、データは残り、量は測られ、条件は分ける。
- 色と形は同時に使う。色だけだと色覚の違いと白黒印刷で種類が消え、形だけだと遠くから種類が見えない。
- 外部は、同じ種類の要素でも自分の側の要素と区別したいときに使う。Discord や Cloudflare のように、こちらが作っていない相手に付ける。
- 条件は、判断や決定のように「分ける」働きの要素にだけ使う。条件で通る矢印は、要素ではなく点線で表す。

## 塗りと線

- 塗りは、種類の色を背景に混ぜた薄い色にする。混ぜる割合は、明るい背景で 17%、暗い背景で 27%。
- 枠は種類の色で 2px。文字は常に本文の色にし、種類の色で塗らない。
- 主役は、色を濃くせず、大きさと文字の太さで示す。
- 外部は枠を `6 5` の破線にする。「あとで作る」「元の文章のまま」のような未確定のものにも、同じ破線を使う。

| 役割 | 明るい背景 | 暗い背景 |
| --- | --- | --- |
| 背景 | `#ffffff` | `#14181c` |
| 文字 | `#1f2933` | `#e8ecef` |
| 補足の文字 | `#5b6672` | `#a3adb8` |
| 薄い線（目盛り） | `#c7d0d9` | `#3a444e` |

塗りの色は次のとおり。

| 種類 | 明るい背景 | 暗い背景 |
| --- | --- | --- |
| 人・エージェント | `#d9e1f1` | `#1d2e4b` |
| システム | `#ede6f8` | `#3e3556` |
| データ・もの | `#d8eeec` | `#1b3f3e` |
| 量・金額 | `#f7e4d9` | `#4f3226` |
| 条件・判断 | `#eddae5` | `#3e2236` |
| 外部 | `#f2f3f5` | `#24292f` |

## 形の描き方

幅 200、高さ 80 の要素を原点に置いたときの `path` を示す。幅と高さの比に合わせて座標を伸縮して使う。形の内側に収まる文字の幅は、カプセルで「幅 − 高さ × 0.55」、楕円で幅の 74%、レンズで幅の 60%、雲で幅の 82%、ほかは「幅 − 28px」。収まらない文字は、折り返すか、形を大きくする。

```text
人・エージェント  M40 0H160A40 40 0 0 1 160 80H40A40 40 0 0 1 40 0Z
システム          M18 0H182Q200 0 200 18V62Q200 80 182 80H18Q0 80 0 62V18Q0 0 18 0Z
データ・もの      M0 14Q0 0 14 0H186Q200 0 200 14V69C164 87 136 60 100 69C64 87 36 60 0 69Z
量・金額          M0 40A100 40 0 1 1 200 40A100 40 0 1 1 0 40Z
条件・判断        M0 40C44 -6.4 156 -6.4 200 40C156 86.4 44 86.4 0 40Z
外部              M100 0C118.6 0 139.5 4.7 155.8 9.3C172.2 13.8 192 20.2 198 27.3C203.9 34.4 197.4 44.1 191.3 51.9C185.2 59.6 176.3 69.3 161.1 73.7C145.9 78 120.2 78.1 100 78C79.8 77.9 55.3 77.4 40 73C24.8 68.7 15 59.5 8.7 51.9C2.4 44.2 -3.9 34.4 2 27.3C8 20.2 27.8 13.8 44.2 9.3C60.5 4.7 81.4 0 100 0Z
```

- 外部の雲は、同じ点列を縦横に伸縮すれば、どの大きさにも使える。要素ごとに雲の凹凸を変えない。
- 入れ物（外側の囲み）に要素を入れるときは、入れ物を種類の形で描き、中の要素より外側に大きく取る。角から中の要素までの距離は、楕円やレンズでは角の分だけ多く取る。中の入れ物は背景色で塗り、枠だけを種類の色にする。

## 線と矢印

- いつも起きる流れは、補足の文字の色の実線にする。条件のときだけ起きる流れは、条件の色の点線（`7 6`）にする。
- 矢印は、始点と終点を結ぶ緩やかな曲線（二次ベジェ曲線）で描く。曲がりは長さの約 14% までにし、30px を超えない。直角に折れる線は使わない。
- 往復する 2 本は、互いに反対側へ曲げ、重ならないようにする。
- 矢印の言葉は、白い縁取り（背景色で 7px の `stroke`）を付けて、線と重なっても読めるようにする。

## 状態の札

進み具合や結果は、種類の色とは別の 4 つの札で表す。記号、言葉、色の 3 つを必ず一緒に付け、色だけに頼らない。

| 状態 | 記号 | 明るい背景 | 暗い背景 |
| --- | --- | --- | --- |
| 完了 | ✓ | `#1a7f37` | `#3fb950` |
| 待ち | ! | `#9a6700` | `#d29922` |
| 失敗 | ✕ | `#cf222e` | `#f85149` |
| 未着手 | – | 外部と同じ灰色 | 外部と同じ灰色 |

札は、高さ 30px の角のない丸い札（`rx` を高さの半分）で、塗りは状態の色を薄く混ぜた色、枠は状態の色、文字は本文の色にする。

## グラフの色

- 1 つの量には 1 つの色相を使い、量・金額の橙を既定にする。系列が 2 つ以上あるときだけ、種類の色から順に割り当てる。
- 順序のある状態（確度、進み具合）は、青の明るい色から濃い色へ並べる。暖色から寒色へ並ぶ温度の勾配は使わない。赤が「失敗」の札と重なり、遅れを前向きと読ませるため。
- 内訳の棒は、同じ色相の濃淡で分け、隣り合う部分の間に 2px の背景色の隙間を空ける。
- 棒の先は 4px 丸める。線は 2〜3px、点は直径 8px 以上にする。グラフの目盛りは薄い線で描き、文字は本文の色にする。

## 色の検証

5 つの種類の色は、明るい背景と暗い背景のそれぞれで、全部の組み合わせについて検証した（dataviz スキルの `validate_palette.js` を `--pairs all` で実行）。

- 色覚のシミュレーション（Machado の 3 種類）でも、全部の組み合わせの色の差（OKLab ×100）が基準を超える。
- 枠の色は、背景に対して明るい背景で 3.5 以上、暗い背景で 3.2 以上のコントラスト比がある。
- 本文の文字は、どの塗りの上でも 9 以上のコントラスト比がある。

色を足したり変えたりするときは、同じ検証を明るい背景と暗い背景の両方でやり直す。

## 描き出し方

- SVG に色をトークン（`--person` などの CSS 変数）として定義し、暗い背景の値を `@media (prefers-color-scheme: dark)` で切り替える。背景は図の中に `<rect>` で描き、貼られた先の背景に左右されないようにする。
- PNG に書き出すときは、明るい版と暗い版を 1 枚ずつ書き出し、貼る先が選べるようにする。
- 見本の SVG（[schematic.svg](../examples/schematic.svg) など）は、そのまま写して座標と文字を直せば使える。
