# ロゴ

固有名詞の横に添えるロゴは、持ち主の決めた形のまま、HTML の中に埋め込んで使う。

- 公式サイトのプレスキットかブランドページから取る。無ければ [Simple Icons](https://simpleicons.org/) の SVG を使う。Simple Icons の SVG は CC0 だが、商標の権利は各社に残る（[ライセンス](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md)）。
- インライン SVG か data URI で埋め込み、外部の URL から読み込まない。読み込みが PNG の書き出しに間に合わないと、ロゴが抜けた画像になる。
- 色、縦横比、形を変えず、各社のブランドガイドに従う。変えたロゴは、見る人には別のものに見える。
- 公式のロゴが手に入らないときは、自分で描かず名前の文字だけにする。描いたロゴは本物と違う形を本物として見せる。
- ロゴを持たない組織は、正式名称の文字だけにする。
