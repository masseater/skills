# masseater-skills

masseater のリポジトリで共通に使うエージェントスキルである。

Stop フックは、masseater のリポジトリで差分が残っているとき、終える前に `masseater-style` と照らし合わせるよう 1 回だけ促す。

フックは、スレッドの開始と解決でタスクグラフを書く。スレッドが最初の進捗チェックリストを投稿すると、フックはそのスレッドのタスクを `graph.json` に足し、チェックリストの見出しをタイトル、進行中のステップを `now` にする。スレッドが解決されると、タスクのスレッドがすべて解決された時点でそのタスクを閉じ、最後の報告の 1 行目を `result` にする。プロジェクトファイルの `status-view/graph.json` が無いセッションでは、何もしない。
