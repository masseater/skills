# delivery

チェックを通過してから本番環境に到達するまでのパスを確認する。パスがローカル環境に依存する場合、チェックを通過していない変更が本番環境に到達する。アプローチとしては、[The Twelve-Factor App](https://12factor.net/) のビルド、リリース、実行、および設定に従うこと。

| 確認項目 | 現在の状態を確認する方法 | 満たすための条件 |
| --- | --- | --- |
| チェックが実行される場所 | ワークフローとフックの設定を確認し、最新の実行結果を main で確認する | push 時に main でチェックが実行され、最新の実行が成功したことを確認する |
| デプロイパス | ワークフローのデプロイジョブを確認する | ローカル環境に依存せず、チェックを通過したもののみがデプロイされる |
| ロールバック | 以前のバージョンを再デプロイする手順を探す | 手順が存在し、実際に一度ロールバックが行われた |
| 環境変数 | `.env.example` とワークフローの環境変数を確認する | 環境ごとに異なる値のみが環境変数であり、変化しない値はコードや設定ファイルにある |
