# 一度きりの作業を仕組みにする

1. 実際に実行した手順を、入力、ツール、認証情報、出力とともに順に書き出す。記憶ではなく、シェルの履歴、セッションが書いたファイル、ツールの呼び出しから取る。
2. 各段階を、決定論的なもの、判断が要るもの、オーナーの手が要るものに分ける。
3. 状況の一覧から各段階の形を選び、決定論的な段階から作る。
4. ツール、バージョン、入力を固定し、ワークスペースかセッション開始フックで宣言する。
5. クリーンなディレクトリにリポジトリをチェックアウトしてコマンドを実行し、最初の結果と比べる。違いがなくなるまで直す。
6. 使い捨てのスクリプト、入力のコピー、手作業の手順のメモを消す。
7. コマンドと、それが作ったものと、静的に確かめられずに残るものを報告する。
