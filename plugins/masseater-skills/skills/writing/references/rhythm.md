# リズム設計の詳細

これらを他の `references/` の規範と併せて適用する。

- 「set up, flow, stop」のビートに合わせて文章を構築する。
- 密度の高い段落と密度の低い段落を交互に配置する。
- 冒頭に未解決の緊張感を1つ作り出す。
- 宣言ではなく、反問や違和感、あるいは告白を含むセクションを設ける。
- 疑問を明示的に解決し、結末を具体的なものに着地させる。
- 文章が状況やドキュメントを更新しているかどうかで、拙い文章からの解放を示す。
- 完成したら、トピック、リーク、緊張感の台帳、ビート、境界の順に精査する。

## 文章のビート

短い文で足がかりを作り、長い文で流れを作り、短い文で止める。「set up, flow, stop」を段落の基本ビートとする。

断定だけで押し通さない。断定と躊躇を交互に繰り返す。

- 断定は「～だった」「～である」「そういうことだ」
- 躊躇は「～に違いない」「～だと思う。だが……」「～なのではないだろうか？」

躊躇は弱さではなく仕掛けである。後に事実によって裏切られる確信が、読者の予測を誘導し、そしてそれを打ち砕くための土台となる。「うまくいっているに違いない」と書き、次の段落で「だが後になって記録を見ると、そうではなかった」とそれを打ち消す。

転換点では、譲歩、転換、短い停止というビートを利用できる。「～になるだろう」「～であり続けるだろう。だがここで扱うのは……だ。それについて考えたい」というように、転換後の短い指示文が読者の視線を固定する。

## 段落の密度波形

密度の高い2〜3つの段落が続く場合は、密度の低い段落を1つ配置する。密度の低い段落の機能は、以下のいずれかに限定される。

- 決着がついた事柄を1行に凝縮する
- 次の判断対象を提示する
- 視点の距離を切り替える

視点の距離を固定しない。記録、数値、備考、コードといった具体的な内容に近づく段落と、意味を持たせるために一段階後退する段落を交互に配置する。

箇条書きは、身体の呼吸を止める間としても利用できる。「要するに、～だ」といった列挙の後に一段階後退する文は、この間があるために機能する。

## 冒頭の設計

冒頭の役割は、最初の数文で未解決の緊張感を作り出すことである。形式は問わない。

- 読者自身の心情の再提示から、仮説へと移行する
- 読者に直接問いかけ、即座に自分なりの答えを出す
- 確信を持って一般的な命題を提示し、その後の本文でその確信を検証する
- 語り手の仮定を肯定的に書き出し、それを事実で打ち消す
- 前章や前節で残された問いを、参加者の言葉を借りて肯定形で再提示する

予告や要約を用いてもよい。「～について考える上で、これ以上ふさわしい切り口はないだろう」といった態度を伴う一文は、それだけで緊張感を生み出す。避けるべきは、「この章ではA、B、Cを扱っている」といった、態度のないアジェンダに過ぎない。予告に態度を持たせるか、あるいは読者の感情や抵抗への対処を予告よりも先に提示する。

読者が抱きやすい抵抗を、まず読者の言葉で、それは古臭い、作為的である、非実用的である、自分には無関係である、などと述べる。簡潔に対処し、その後に本題に入る。

## セクションへの入り方

セクションの冒頭で「このセクションでは～を扱っている」と宣言してはならない。以下のいずれかで入る。

- 前節で残された違和感を、参加者の問いとして再提示する
- 読者が自然と抱くであろう反問を、そのまま書き出す。すぐに答えず、一度受け止めてから打ち消す。
- 書き手の告白で入る。その告白を、その後に続く論旨の足掛かりとする。

読者の中に「まだ名前のついていない違和感」を生み出した後、答えとしてではなく、命名として理論や概念、引用を盛り込む。理論を先に提示し、例を挙げて裏付けることは、読者から発見を奪うことになる。

セクション間の橋渡しは、前のセクションの末尾ではなく、次のセクションの冒頭に配置する。前のセクションの末尾に「次は～について見ていく」という予告を加えることは、経過をナレーションすることであり、拙い文章である。

## 列挙の導入

性質やカテゴリーを列挙した後は、直前の具体的な場面に各項目を一つずつ配置する。「一つ目は、今見た……の真の姿だ」や「二つ目も心当たりがある」といった具合に書く。導入のスタイルを統一してはならない。真の姿の指摘、心当たりの提示、特定の事実へのマッピング、そして未来の断念や変更など、多様な手法を使い分ける。

## 疑問の解消と結末

途中で生じた疑問は明示的に解消する。「これが答えの半分だ」「残りの半分は……にある」といったように、疑問を半分ずつ返すことで、後半に勢いを与える。

結末では、読者がすでに持っている具体的な事柄について、蓄積された抽象論を展開し、その後に締めくくる。冒頭の場面や、読者自身の体験、序盤の疑問などがそれにあたる。どの緊張感を回収するかを選択し、最後に一つだけ空けておいてもよい。

二人称の呼びかけ、読者への依頼、そして書き手の謙遜や断り文句は、章の冒頭や結末といった境界においてのみ解放として機能する。それらを中盤の論旨に混ぜ込んではならない。

## 拙い文章からの解放を伝える

判断軸はただ一つ。文が状況を更新するのか、それとも文書を更新するのか。

- 状況を更新する文は、解放として残してもよい。
- 文書を更新する文は、原則として削除する。

状況を更新する文は、原則として削除する。

文書を更新する文は、この章やこの節、あるいはこれまでの物語が「どう見えるか」、あるいは「次に何が書かれるか」を伝えるのみである。

### 典型的な拙い文章

いずれの場合も、主題はテキストそのものであり、状況に関する情報は一切ない。

- 「今のところは、おそらく概念の説明に見える。では、すぐに例に戻ろう。」
- 「要するに、この章のテーマは……ではなく……」
- 「誤解しないでほしい。……を否定するつもりはないのだが……」
- 「技法は列挙しない」「これは……についての話ではない。問題は単に……だ」
- 「先に答えの半分を提示しよう」「最後にもう一度、線を引いておこう」
- 「ここまでで……を見た。次の質問は……」「次は……を見る」

拙い文章は、短い断定形としても現れる。文書を更新する文が短い断定調に作り直すと、オチのように見え、残りやすい。これが拙い文章が陥る最大のパターンである。短くリズムが良いからといって、そのままにしておくべき理由にはならない。

### 典型的な優れた解放

いずれも、状況や語り手の判断を更新するものである。

- 「うまくいっているはずだ」というのは前提であり、後で土台を築くための土台である。
- 「まあ、今すぐに対処すべきことではないが、いずれ整理が必要になるだろう」というのは判断上の留保である。
- 「最初から分かっていたなら、そうしていただろうにというのはもどかしい」というのは、判断ミスを露呈させる感情である。
- 「そうしたかったと思う」というのは反問への譲歩であり、その後の展開への足がかりである。

### 文書を更新する文で、そのままにしておいてもよいもの

文書に関する文であっても、保持できる形式は以下の4つに限られる。

1. 読者による特定の誤読や反論を引用して片付ける文。漠然と「誤解しないでくれ」と述べるだけの文は、拙い文章である。
2. 問いを提起し解決する文で、緊張感が高まった後の境界線に配置される文。テキストが何ではないかを宣言する文は、問いを提起するものではない。
3. 読者への要請文や、境界線に配置される免責事項。
4. 「仮に……」と想像上の例や場面の枠組みを開き、「冒頭の例をオチにしよう」と締めくくる文。

### 修正方法

1. 文書を更新するだけの文を削除し、その前後を読む。結びついていれば完了である。
2. 削除によって論理が飛躍した場合は、当該文が状況の側面として何を示そうとしていたのかを、文として書き直す。
3. 書き直した結果でもテキスト自体が話題になる場合は、文全体を削除し、前後の記述をつなぐ橋渡しを再構築する。

「今のところは概念の説明のように見える」という文は、「冒頭の失敗にはこれら3つの特性すべてが揃っている」となる。

## 執筆後の精査

1. トピックテスト。段落の最初の一文と独立した短い文をすべて拾い上げ、それが状況や文書を更新しているかどうかを判定する。
2. リークテスト。「答えの半分」「緊張感」「解決」「線を引く」といったこれらの規範の語彙が本文中に現れるかを確認する。もし現れる場合は、それは仕掛けを宣言している証拠であるため、内容の側面で改めて認識する。
3. 緊張感の台帳。提起した問い、前提、約束を列挙し、それぞれが解決される箇所を指し示す。指し示せないものについては、解決を付け加えるか、削除する。
4. ビート精査。3つ以上の長い断定文が続く場合は、短い足がかりや区切り、あるいはためらいを挿入する。
5. 境界精査。二人称の呼びかけ、要求、あるいは謙譲表現が本文の途中に現れている場合は、それらを境界に移動させるか、削除する。

推敲中に新しく書かれた、あるいは再分割された短い文は、質の低い文章が紛れ込む経路となる。執筆直後に、それらもトピックテストにかける。

## 症状から処方箋を導き出す

| 症状 | 原因 | 処方箋 |
| --- | --- | --- |
| どの段落も同じトーンで、疲れる。 | 文にビートがない。 | ビート精査を適用する。 |
| 正しいが、読み進めようという意欲が湧かない。 | 未解決の緊張感がない。 | 冒頭に緊張感を持たせ、緊張感の台帳で常にオープンであることを確認する。 |
| 理論セクションの温度が急激に下がる。 | 違和感が生じる前に理論が提示される。 | 理論の前に反問や告白を添え、シーンに列挙を着地させる。 |
| 緩い文があるにもかかわらず、締まりがない。 | リリースが進行の叙述になっている。 | トピックテストにかけ、状況の側面で一文として書き直す。 |
| 章の終わりが説教調になっている。 | 抽象的なまま締めくくられている。 | 読者が把握している具体的な内容で着地させ、未解決の疑問を一つ残す。 |
| 冒頭が事務的になっている。 | 態度のないアジェンダになっている。 | 予告に態度を持たせるか、読者の感情や抵抗感への対処を先に行う。 |
