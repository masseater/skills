# 文頭の接続詞を外して読み直す

解説文の下書きを公開する前に、この手順を行う。接続詞は、外すと読者がつまずく箇所にだけ残る。

## なぜ必要か

文頭の接続詞は、書き手の杖である。ある文から次の文へ、書き手自身の思考の流れを運ぶ。隣り合う文から意味の流れを読み取れる読者に、杖は要らない。下書きのまま残すと、書き手がまだ考えている途中のような文章になる。

下書きの段階で接続詞を禁じると、書き手の手が止まる。接続詞をすべて残すと、完成した文章が接続詞で重くなる。この手順は、自由に下書きを書く作業と、あとで外す作業を分ける。

## 手順

1. 思いつく接続詞をすべて入れて下書きを書く。考えている間は遠慮しない。
2. 下書きをコピーし、以降はコピーで作業する。原本から外すと、接続詞があった位置が分からなくなる。
3. コピーの文頭にある接続詞をすべて削除する。
4. コピーを頭から声に出して読み、読みが止まった箇所に印を付ける。
5. 印を付けた箇所にだけ、接続詞を戻す。ほかの箇所は外したままにする。
6. 原本をコピーで置き換える。

この手順を教えた編集者の経験では、戻る接続詞はたいてい「でも」だった。逆接は議論の向きを変えるので、隣り合う2文から読者が推測できない。添加や順接の接続詞は、文の内容から補えることが多い。

## 外す範囲

外すのは文頭の接続詞だけである。原因と理由を1つの文の中で結ぶ接続詞は、[`ai-style`](../references/ai-style.md) の通り残す。

## 声に出して読む目的

声に出して読むのは、論理が途切れる箇所を見つけるためである。読点を打つ位置は決めない。句読点は [`punctuation`](../references/punctuation.md) に従う。印を付けるのは、直前の文との関係を読者が判断できずに止まる箇所だけである。

エージェントは声に出して読めない。外した接続詞ごとに前後の2文を読み、接続詞なしでも両者の関係が分かるかを判断する。分からなければ接続詞を戻す。迷うときも戻す。必要な接続詞が欠けたときの読者の損失は、余分な接続詞が1つ残る損失より大きい。

## 機械で確かめられる範囲

- 文頭の接続詞は機械的に列挙できる。リンターは段落ごとに数え、連続する2文がどちらも接続詞で始まる箇所を指摘できる。しきい値は既存の文章で測定して決める。
- 手順3は機械的な処理である。コードモッドは、接続詞を外したコピーと、外した位置の一覧を出力できる。
- 接続詞を外してよいかどうかは判断である。判断モデルは接続詞ごとに残すか外すかを選ぶだけにし、迷うときは原文のままにする。
