# 要素を動かして見た目を決める

1. 対象が Vite の React アプリか確かめる。違えば、このスキルは使わない。
2. made-refine を、そのリポジトリの流儀で `devDependencies` に足す。`init` は使わず、[`made-refine`](../references/made-refine.md) の手順で、開発時だけ `<DirectEdit />` を描画する。
3. 開発サーバーを起動し、持ち主のブラウザで開ける URL を伝える。届かないときは、持ち主に伝えて止まる。ページが白紙でないことを、自分でも確かめる。
4. 持ち主に、`Ctrl + .`（Mac は `Cmd + .`）で編集画面を開き、要素をクリックして動かし、右下のコピーボタンで差分をコピーして貼るよう伝える。
5. 貼られた差分を受け取る。`selector` と `context` で要素を見つけ、`edits` の値を、そのリポジトリのスタイルの書き方に直して反映する。`source` の行番号は、実際のファイルとずれることがあるため、探す手がかりにだけ使う。
6. 持ち主が「これで確定」と言うまで、4 と 5 を繰り返す。
7. 確定したら、2 で足した依存と `<DirectEdit />` を取り除き、`git diff` で、反映した見た目の変更だけが残っていることを確かめる。
