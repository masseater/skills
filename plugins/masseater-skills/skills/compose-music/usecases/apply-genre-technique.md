# ジャンルの手法を調べて当てはめる

ジャンルの決まったパート（ドラム、ベース、ミックス）を作るとき、直すとき、持ち主がパートを「普通」「退屈」「そのジャンルらしくない」と言ったときに使う。

1. そのジャンルのそのパートの作り方を Web で検索し、制作の解説を読む。取り出すのは plan に書ける値（スウィングの割合、ステップの位置、発ごとの強弱、処理の順）だけにする。解説のリンクは報告のために残す。
2. そのジャンルの参照曲を、古いものと新しいものを混ぜて 10 曲以上 PC に集める。1 曲から分かるのはその曲の癖で、ジャンルの癖ではない。
3. 参照曲のパートを、[`separate-drums`](../references/separate-drums.md) のステップごとの手順で測る。参照曲を読む前に、plan という正解のある自分の曲を同じ道具で測り、plan どおりの値が返ることを確かめる。
4. 自分の曲の同じパートを、DAW のバスのステムで同じ道具を使って測り、参照曲の中央値と範囲に並べる。小節から次の小節へ同じセルが繰り返される割合も比べる。繰り返しが参照曲と同じなら、変化を足しても直らない。差はスウィングか発ごとの強弱にある。
5. 差の大きい項目から、plan を参照曲の中央値に寄せる。解説と測った値が食い違うときは、測った値に従う。持ち主が決めたこと（拍子、ジャンル、テンポ）は動かさない。
6. DAW に組む前に、plan をトラックのゲインだけで合成し、同じ道具で測る。DAW での組み直しは数分かかり、合成は数秒で済む。
7. DAW に組み、バスのステムとメインを書き出して両方を測る。パートが参照曲の範囲に入り、[`verify-audio`](verify-audio.md) の検査にも通ることを確かめる。バランスを変えてメインの帯域の比が動いたときは、バスのイコライザーで戻す。トラックを下げ直すと、合わせたばかりのバランスが崩れる。
8. 報告には、測った差、変えた内容、解説のリンクを書く。

UK ガレージのドラムを測った値は [`uk-garage-drums`](../references/uk-garage-drums.md) にある。ジャンルかパートが違うときは測り直す。
