# ドラムパターンを組む

1. コードを書く前に、テンポ、長さ、パターンを 16 分音符のステップで決める。パターンはデータ（plan の JSON）として書く。トラックごとに各小節のステップ番号を並べ、裏のステップに掛けるスウィングの量を添える。スウィングするステップは、ステップの何分の一かだけ遅らせる。
2. ワンショットは取り込む前に固定の長さに切り、フェードをかける。`ffmpeg` の `atrim` と `afade` を使い、`volume` でピークを決まった値にそろえ、48 kHz のモノラルにする。
3. 楽器ごとに 1 トラック、1 発ごとに 1 クリップとし、パターン全体が 1 回の取り消しで戻るように置く。DAW の中の置き方は、その DAW のスキルに従う。
4. グルーヴのための 1 発ごとの音量の揺らぎ（ベロシティ）は、拍の頭を強く、裏を弱くするアクセントに、シード固定の乱数（±1〜2 dB）を足し、0.5 dB に丸める。DAW がクリップのゲインを書き出しに反映しないときは、音量を変えたサンプルのソースを 1 発ごとに差し替える。音量違いのソースは `ffmpeg -af volume=<dB>dB` で作り、`pcm_f32le` で書いてクリップを避ける。クリップと音量の対応は plan に残す。
5. トラックのレベルは、耳ではなく、ステムを測ってから決める（[`verify-audio`](verify-audio.md)）。
