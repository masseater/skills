# リファレンス曲を分析する

使うモデルとそのライセンス、動かす場所は [`reference-tools`](../references/reference-tools.md) にある。成果物は PC の `%USERPROFILE%\sandbox\music\<曲名>\reference\` に置き、持ち主がそのまま開けるようにする。

1. リファレンスは PC 上で `yt-dlp` でダウンロードする（クラウドからは YouTube に届かない）。音声（`-x --audio-format wav`）と動画の両方を取る。
2. 先に動画を見る。解説動画には DAW のノートエディターが映っていることが多い。`ffmpeg` でフレームを抜き、ノートエディターを切り出して拡大し、画面からテンポと音の位置を読む。グリッド上の印は正確なので、ここで読めた値は以降の推定より優先する。
3. 音声を 44.1 kHz のステレオ 16 ビット WAV にし、ステムに分離する（`stems/`）。分離したステムを足し戻した波形と元の音声の差のエネルギーを測り、分離で失われた量を報告に残す。
4. テンポは、ドラムのステムのオンセット強度の自己相関で推定し、画面に出ているテンポと突き合わせる。オンセットに 16 分音符のグリッドを当てはめる。フルミックスのオンセットは使わない。ボーカル、コード、ベースが偽のオンセットを足すからである。スウィングとハットの並びは [`separate-drums`](../references/separate-drums.md) の手順で測る。
5. 音声を MIDI にする（`midi/`）。楽器ごとに 1 ファイルにし、拍のグリッドは手順 4 のテンポに合わせる。
6. MIDI を `.fumx` にする（`fumx/`）。`vp exec midi-to-fumx <file>` は書いた `.fumx` を読み戻して元の MIDI と比べるので、失敗したら変換を信用しない。
7. 作曲者の癖を取り出す（`report.md` と `habits.json`）。`vp exec song-report` の調、拍ごとのコード、繰り返す小節を元に、次を数える。
   - コード進行と転調、セクションの構成と長さ
   - ボイシング：転回形、最低音と最高音の音域、テンションの種類と頻度
   - ベース：ルート以外の音の割合、音の長さ、リズムの型
   - メロディ：音域、跳躍の大きさの分布、フレーズの長さと始まる拍
   - リズム：パートごとのステップの分布、スウィング、拍に対するずれの中央値（前ノリか後ノリか）
   - ベロシティの分布と、拍の位置ごとの強弱
8. 音色を分析する（`timbre/`）。パートごとに、同じ種類の区間のオクターブ帯域ごとのエネルギー、スペクトル重心、アタックとディケイの時間を測る。キックは 35〜140 Hz の最も低いピークの高さ、60〜250 Hz の割合、ハットは明るさも見る。
9. 音色の候補を順位づける（`timbre/candidates.json`）。PC にあるサンプルと DAW のプリセットを候補にし、候補ごとに `.fumx` の同じ区間を鳴らして書き出し、ステムとの埋め込みの類似度と手順 8 の特徴量の差で並べる。上位 5 つを残し、1 位を既定とする。ワンショットは `asetrate` でピッチを、EQ で帯域をステムに寄せ、もう一度測る。
10. DAW のセッションに、ステムのトラックと、`.fumx` から作った MIDI のトラック（1 位の音色）を同じタイムラインで並べる。置き方は、その DAW のスキルに従う。
11. 報告には、測った値、手順 3 の分離で失われた量、手順 5〜9 の校正の結果、音色の候補を書く。持ち主には、音色の候補を聴き比べて差し替えればよいことだけを伝える。何もしなければ 1 位のまま [`make-song`](make-song.md) に進む。

## 校正

手順 3、5、9 を初めて使うとき、モデルかその版を替えたときは、リファレンスに掛ける前に正解の分かる音で校正する。

- 分離と MIDI 化：手持ちの `.fumx` をサンプルで鳴らしてミックスを作り、手順 3〜6 にかけて、元の `.fumx` とのノートの一致率（音高と 50 ms 以内の開始）をパートごとに出す。フルミックスに掛けた MIDI 化とステムに掛けた MIDI 化を両方試し、一致率の高い方をそのパートで使う。
- 音色の順位：ステム自身から切り出した区間を候補に混ぜ、1 位に来ることを確かめる。来ないときは、その特徴量か埋め込みで順位を決めない。
