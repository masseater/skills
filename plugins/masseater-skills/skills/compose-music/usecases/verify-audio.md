# 聴かずに出来を確かめる

1. DAW からトラックごとのステムを書き出す。書き出し方は、その DAW のスキルに従う。あわせて、セッションの全クリップの開始時刻を秒にして JSON に書く。これが期待するタイムラインである。
2. ステムをクラウドに送り、[`verification-metrics`](../references/verification-metrics.md) の検査を実行する。見るのは、期待するタイムラインに対するトラックごとのオンセットのタイミング、スウィング、トラックごとと合算のラウドネス、ピーク、クリップ、ループ内の無音、スペクトルのバランスである。
3. 検査に落ちたら、セッションのパターンかレベルを直し、手順 1 から検査をやり直す。報告するのは測った値と、直した内容だけにする。
4. 音声を入力できるモデルに聴かせるときは、[`listening-models`](../references/listening-models.md) に従い、先に正解の分かる対照の音で校正する。校正を通らなかった項目は、聴いた結果として報告しない。
5. 報告には、音を聴いていないこと、持ち主の判断（好み、ノリ）が残っていることを書く。
