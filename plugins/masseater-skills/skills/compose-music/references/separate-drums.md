# ドラムを分離してスウィングとハットの並びを測る

ミックスにボーカルやコードが混ざっていると、ハットのオンセットを直接測れない。ドラムだけを分離し、ハットの帯域のオンセットを 16 分ステップのグリッドに当てて測る。Python は使わない。

## 手順

1. 音声を 44.1 kHz のステレオ 16 ビット WAV にする（`ffmpeg -ar 44100 -ac 2 -sample_fmt s16`）。
2. ドラムを分離する。モデルは Hugging Face の `StemSplitio/htdemucs-ft-drums-onnx` の `htdemucs_ft_drums_fp16weights.onnx`（約 166 MB、MIT）を使う。`onnxruntime-node` で `mix`（`[1, 2, 343980]`、7.8 秒）を入れ、`stems`（`[1, 4, 2, 343980]`、順序は drums、bass、other、vocals）を受け取る。STFT はモデルの中にある。7.8 秒の窓を 4 分の 1 重ねて並べ、重ねた部分は直線の窓でつなぐ。28 秒の分離は CPU の 4 コアで約 25 秒かかる。
3. 分離したドラムの 6〜16 kHz の帯域でオンセットを取り、キックの帯域（40〜130 Hz）の並びで 4 小節の位相を合わせる。ハットは、オンセットの位置を 2 ステップで割った余りの分布から、偶数ステップと奇数ステップのずれを出す。奇数ステップの遅れが `d` ステップなら、スウィングは `50 * (1 + d)` %である。
4. 1 拍あたりのハットのオンセット数で密度を見る。4 なら 16 分、2 なら 8 分である。

スクリプトは `/mnt/project-files/luna-ukg/` の `sep.mjs`（分離）、`hats.mjs`（オンセットの解析）、`mk.mjs`（対照の音の生成）である。

## ステップごとの発音率と強さを測る

ハットだけでなくパターン全体を参照曲と比べるときは、分離したドラムを 3 つの帯域で測る。110 Hz 未満がキック、300 Hz〜4 kHz がスネアとクラップとリム、7 kHz 以上がハットである。

1. 各曲の最初の 210 秒を分離する。16 論理プロセッサーの CPU で、146 秒の音声は 1 本だけなら 73 秒、210 秒の 3 本を同時に動かすと 1 本あたり約 7 分かかる。`onnxruntime-node` の DirectML はこのモデルでメモリー不足になるので、CPU で動かす。
2. 帯域ごとにオンセットの強さを取り、120〜145 BPM の範囲で、オンセットを小節の長さで折りたたんだ分布が最も鋭くなるテンポを選ぶ。位相は、ステップ 0 のキックとステップ 4、12 のバックビートから決め、キックが入り直す点が小節線に乗ることで確かめる。
3. 小節とステップごとに、ステップの近くの最も強いオンセットを取る。奇数ステップの窓は 0.55 ステップ遅れまで広げ、スウィングした発をそのステップに数える。出すのは、ステップごとの発のある小節の割合と強さの中央値、1 小節の発数、小節のパターンの種類の数、次の小節でも同じになるセルの割合、帯域ごとのスウィングである。
4. スネアの胴は、ステップ 4 と 12 で 110 Hz 未満にもキックの 3 分の 1 ほどの強さで出る。低域が強いところだけをキックと読む。

スクリプトは同じ場所の `drumstem.mjs`（複数のファイルの分離）と `refgroove.mjs <ドラムのステム> <開始秒> <秒数>`（測定）である。`mockdrums.mjs` は plan のドラムをトラックのゲインだけで合成し、DAW に組む前の plan を測れるようにする。

校正（2026-11-28）：キックがステップ 0 と 10、バックビートがステップ 4 と 12、スウィングが 58% の plan から作った曲を分離して測ると、同じステップと 57〜58% が返った。キックをミックス全体の低域から取る版は、ベースがその帯域を埋めるので失敗した。

## 校正の結果（2026-11-28）

リファレンスを測る前に、サンプルから正解の分かるループを作り、同じ手順にかけて、正解を取り戻せるかを確かめた。

| 対照の音の奇数ステップの遅れ | 測った遅れ（分離なし） | 測った遅れ（分離あり） |
| --- | --- | --- |
| 0 | 0.002 | 0.003 |
| 0.2 | 0.192 | 0.171 |
| 0.5 | 位相の折り返しで -0.5 | 位相の折り返しで -0.5 |

分離しても遅れは 0.03 ステップ以内で戻る。0.5 は 1 ステップの半分で、折り返してしまう。

リファレンスの 15〜43 秒と 43〜58 秒を測ると、奇数ステップの遅れは -0.03 と -0.04（スウィング 48%）だった。別の方法（ハーモニックとパーカッシブの分離）の 51% とも合うので、リファレンスのハットは、ほぼストレートである。ハットは 1 拍に約 1.9 発で、16 分を刻み続けるのではなく、偶数ステップが強く、奇数ステップが弱い。リムとキックの位置は、分離したドラムでも分布が散って確定できなかった。

## 限界

- ボーカルやコードが強い区間では分離にハットが混ざり、位置の分布が散る。区間を変えて 2 回以上測り、結果が合うことを確かめる。
- オンセットの時間分解能は約 3 ms で、ステップの 1 割（約 11 ms）の遅れまで見分けられる。
