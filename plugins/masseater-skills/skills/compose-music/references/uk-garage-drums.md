# UK ガレージのドラムを測った値

2026-11-28 に、15 曲（2 ステップとスピードガレージ、古いものと新しいもの）のドラムのステムの最初の 210 秒を、[`separate-drums`](separate-drums.md) のステップごとの手順で測った。ステップは 0 から数える 16 分音符で、1 拍目がステップ 0、バックビートがステップ 4 と 12 である。

## 参照曲の値

- テンポは 125〜137 BPM で、中央値は 132 である。
- スウィング：11 曲で奇数ステップが 62〜71% の位置に来る（中央値 66%、ほぼ 3 連符）。4 曲は 50〜56% である。1 曲の中では、キック、ゴースト、ハットのスウィングはほぼ同じ量である。
- ハット：10 曲で、裏拍のハット（ステップ 2、6、10、14）が 7 kHz 以上の最も強いオンセットで、バックビートと同じ強さである。その間の発は、裏拍の 4 分の 1 から半分の強さである。ハットのオンセットは 1 小節に中央値 9.4 発（7.3〜15.6）ある。
- ゴースト：小さなリムとスネアが、スウィングした奇数ステップ（7、9、11、13、15）に、主な発の 20〜45% の強さで入る。
- キック：13 曲が 93〜99% の小節でステップ 0 にキックを置く。2 発目はステップ 10、7、3、11、13 のどれかである。3 曲は 4 つ打ちである。
- バックビート：13 曲が 89〜99% の小節でステップ 4 と 12 の両方に置く。
- 繰り返し：次の小節でも同じになるセルは 78〜97%（中央値 91%）である。最も発の多い小節のハットは、平均の小節の 1.7 倍までで、そこがフィルである。

## 解説と測った値の違い

制作の解説はスウィングを 55〜65% と書く（[Attack Magazine](https://www.attackmagazine.com/technique/beat-dissected/found-sound-2-step/)、[The Producer School](https://theproducerschool.com/blogs/featured-blogs/uk-garage-resurgence-how-the-new-wave-kettama-sammy-virji-interplanetary-criminal-differs-from-the-originals)）。測った中央値は 66% である。減衰の短い裏拍のハット、発ごとの強弱、シンコペーションのゴースト、16 分 3 連のフィル、2 小節か 4 小節ごとの終わりの変化は、解説と測った値が一致する。

## 持ち主の判断

- ベースが小節線をまたいで伸び、コードがステップ 14 で次の小節を先取りし、ステップ 0 にコードが鳴らない版は、持ち主に 7 拍子に聞こえた。低域のアクセントはステップ 3、6、10、13 に並んでいた。
- キックがステップ 0 と 10、バックビート、スウィング 58%、ハットがクラップより小さい版は、持ち主に普通すぎると言われた。
- 持ち主が受け入れた版の設定は次のとおりである。
  - スウィングは 66%。
  - 裏拍のオープンハットを 7 kHz 以上でバックビートと同じ強さにし、クラップとスネアを下げる。
  - スウィングした奇数ステップにゴーストのハットを置く。
  - ゴーストのリムは 3 つのピッチで、2 小節の掛け合いにする。
  - ゴーストのキックはステップ 7 と 11 に 8 dB 下げて置き、サイドチェインのポンプの対象から外す。
  - 後半に、拍の頭にアクセントのあるシェーカーを足す。
  - 4 小節ごとの終わりに 16 分 3 連で上がるリムのロール、8 小節ごとの終わりにスネアのロールと逆再生のクラップを置く。
  - 全小節でステップ 0 のキックとバックビートを残す。
- 16 分 3 連は、66% でスウィングした 16 分と同じグリッドに乗るので、3 連のフィルは拍子を乱さない。
