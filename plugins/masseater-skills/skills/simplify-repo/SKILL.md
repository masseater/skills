# simplify-repo

対象は main ブランチ全体。差分だけ、自分が担当した分だけを見ることはしない。経緯、変更履歴、作業者の意図は見てよいが、全体を見る代わりにはしない。

1. まず oxlint、fallow、steiger 等の機械的検出がリポジトリ全体で動いていることをチェックする
2. simplify-reviewer に main 全体をレビューさせる
3. 指摘を作業の一覧にする。採否はすべて自分で判断して進める
4. 機械が断言できるもの、統合、文書の順に意味の単位で PR を入れる
5. 終わったと思ったら再度レビューさせる
6. 満たしていなければ完了とせず直してレビューを繰り返す
