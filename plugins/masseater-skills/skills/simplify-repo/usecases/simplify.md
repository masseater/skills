# リポジトリ全体を簡素化する

1. まず、oxlint、fallow、wism、y8、fu4、h56mなどのメカニカル検出器がリポジトリ全体をスキャンしているか確認する。
2. [references/reviewer.md](../references/reviewer.md) の全文をプロンプトにしたサブエージェントに、メインブランチ全体をレビューさせる。
3. 検出結果をタスクリストにする。一つひとつを自身で決定し、進める。
4. PRを意味の単位で、この順に取得する：マシンが主張できること、集約、ドキュメント
5. 完了したと思ったら、再度レビューしてもらう。
6. 結果が納得いかない場合は、完了とせず、修正してレビューを繰り返す。
