# 台詞をBGMの拍に合わせる

1. `make`で動画を作ってから`render`し、`apps/videos/out/<名前>/`にMP4を書き出す。
2. 拍のタイムラインのページ（[Beatline](https://claude.ai/artifact/8AGmEPEFMR1zkNKoB7Lom4)）を、その動画に差し替えて公開し直す。ページの`data.json`に、BPM、最初の拍の秒、BGMの波形の山（10ミリ秒ごと）、カットと台詞の秒を書く。動画は音を抜いたMP4、音はBGMだけ（`bgm.mp3`）と台詞だけ（`voice.mp3`）に分けて置き、ページで台詞を消してBGMだけを聞けるようにする。台詞とBGMの音量は動画と同じにする。
3. 持ち主に、タイムラインをダブルクリックするか`M`で、句を始めたい拍にマークを打ち、句をメモに書いてもらう。
4. マークはページのデータベースの`marks`に入る。`ArtifactData`の`list`で読み、各マークの秒をカットの`at`に書く。拍に乗るマークは`onBeat(<拍>)`、動画の頭は`VIDEO_START`で書く。
5. 句が次のマークまでに収まらないときは、そのカットの`speed`を上げる。
6. `voice`と`render`をやり直し、ページを新しい動画に差し替えて、持ち主に確かめてもらう。
