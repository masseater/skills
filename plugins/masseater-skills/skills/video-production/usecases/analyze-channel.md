# 参照チャンネルを分析する

1. チャンネルの最近のショートを4本以上選ぶ。再生数の多い順に選ぶと、視聴者に効いた型が分かる。
2. 各ショートから4枚ずつ画面を取り、チャンネルごとに1枚の一覧画像にする。動画を落とせない環境の取り方は[`masseater-dev`](../references/masseater-dev.md)に書いてある。
3. 一覧画像から次を読み取り、[`channel-styles`](../references/channel-styles.md)に1行足す。
   - 字幕：位置、大きさ、太さ、縁取りや箱の色、話者ごとの色分け
   - 題名：出しっぱなしの帯があるか、色と大きさ
   - 背景と素材：写真、イラスト、画面写真、実写、端末
   - 立ち絵：人数、大きさ、位置
   - つかみ：最初の画面で何を一番大きく出すか
4. 動画を落とせたら、次を測って同じ行に書く。
   - カットの間隔：`ffmpeg -i <動画> -vf "select='gt(scene,0.3)',showinfo" -an -f null -`の`pts_time`から、ショットの長さの中央値と最初のカットの時刻を出す。背景が動かない掛け合いの型は0.08まで下げないと字幕の切り替えを拾えない。
   - 音：`-af ebur128`の統合ラウドネスと、話していない間の音量の下限。下限が −45 dBより上ならBGMがある。
   - 声：ナレーション、歌、声なしのどれか。
   - 音のアクセント：カットから0.15秒以内に音が立ち上がるカットの割合。
5. その型で1本作り、参照の画面と並べて差がなくなるまで直す。直して効いた見た目は共通部品に足す。

画面だけでは、カットの間隔と音は分からない。動画を落とせないチャンネルは、近い型の測った値を当てる。
