# 登場人物

台詞は、この表の人物が実際にそこにいると感じる言い回しで書く。説明文を2人に割り振っただけの台詞は、人物ではなくナレーションに聞こえる。公式設定は口調まで決めていないので（[ずんだもんのガイドライン](https://zunko.jp/guideline.html)）、この表は持ち主が決めた配役である。

| | 春日部つむぎ | ずんだもん |
| --- | --- | --- |
| VOICEVOXの話者 | 8 | 3 |
| 役 | 敏腕エンジニア。解説し、乗り換えを勧め、つまずきを直す | 一般エンジニア。困る、驚く、合いの手を入れる |
| 一人称・二人称 | あーし・きみ | ボク・つむぎ |
| 口調 | 明るいギャル口調で言い切る（〜じゃん、〜っしょ、〜だよね） | 語尾は「〜のだ」「〜なのだ」。素直に反応する |
| 知っていること | 仕組みと最新の更新まで | 普段打つコマンドだけ |
| 台詞の傾向 | 自分の体験から言う（「これ味わっちゃうと、もうnpmには戻れないっしょ」） | 見る人の気持ちを代弁する（「npmのインストール遅すぎるのだ」） |

- Story Spineの「Every day」の不満、「Because of that」の驚き、「Until finally」のつまずきはずんだもんが言い、「One day」の提案、仕組み、解決はつむぎが言う。
- 締めは、つむぎの決め台詞にずんだもんが乗る形にする（「ボクも今すぐ変えるのだ！」）。見る人の行動をずんだもんが先にやって見せる。
- 字幕の色は話者で分ける（つむぎは白、ずんだもんは黄緑）。

## 立ち絵

| | 春日部つむぎ | ずんだもん |
| --- | --- | --- |
| 素材 | 公式立ち絵PSD（`tsumugi3.psd`） | 坂本アヒル「ずんだもん立ち絵素材」PSD（`zundamon.psd`） |
| 目パチ | `!目/*閉じ`と`!目/*基本目セット` | `!目/*UU`と`!目/*目セット` |
| 口パク | `*お`（半開き）、`*わあ`（開き） | `*ほあ`（半開き）、`*ほあー`（開き） |
| 黙っている口 | `*ほほえみ` | `*むー` |

- ずんだもんの服は常に`*服装1/*いつもの服`を指定する。`*服装2`（素体、ぱんつ、スク水、バスタオル）は使わない。
- `!目`の直下の差分（`*〇〇`、`*にっこり`など）は目パチより後に並べる。前に置くと目パチが`!目`を上書きする。
