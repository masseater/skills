# masseater-ecosystem

- テックスタックの完成形と、開発と借用の境界については、[`tech-stack`](references/tech-stack.md)を参照すること。

## なぜこのスキルが必要で、どのような状態を目指すべきか

このスキルが必要な理由は、AIが技術を選択する際、一般的な開発者向けの回答でその隙間を埋めるからだ。一般的な回答は、多くの人に影響を与え、他の環境でも通用するOSSのアップデートフローに沿った汎用的な選択肢を推奨する。masseaterは自社のためだけに開発を行い、ベンダーロックインを容認し、気になる点があればすぐにAIで修正するため、そうした回答は当てはまらない。逆に、AIにとって記述は高速であるため、境界がなければ言語仕様に沿ったコア部分まで作り始めてしまい、ツールの開発自体が目的となってしまう。

このスキルが実現すべき状態とは、masseaterが単に「これが欲しい」と言っただけで、手作業を一切必要とせずに構築・動作する状態のことだ。
