# 一覧の項目を持ち主に渡す

1. 項目が [`agreed-line`](../references/agreed-line.md) に載っていることを確かめる。載っていなければ渡さず、AI が決める。
2. その項目のうち AI が測れる、見られる部分を済ませ、候補を絞る。
3. 候補から既定値を選び、成果物に入れて完成させる。持ち主が答えなくても成果物はそのまま使える状態にする。
4. 持ち主には、決めてほしいことを 1 つの問いにし、絞った候補と選んだ既定値、それぞれを聴く、確かめるための場所（ファイルやセッションの位置）を添えて渡す。
5. 持ち主が直したいときに、どこを開けばどこが変わるかを一行で書く。
