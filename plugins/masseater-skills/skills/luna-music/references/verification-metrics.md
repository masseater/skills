# ドラムパターンを検証する指標と合格の基準

測るのは、書き出したメインバスではなくステムである。

| 項目 | 測り方 | 合格 |
| --- | --- | --- |
| トラックごとのタイミング | 各ステムのオンセット（2 ms フレームのエネルギーの立ち上がり）を取り、期待する各発と 12 ms 以内で対応づける。 | ずれの中央値が 1 ms 未満、最大が 5 ms 未満で、サンプルで説明できない未対応の発がない。 |
| スウィング | 奇数番の 16 分ステップの遅れの中央値をステップ単位で出す。スウィングの割合は `50 * (1 + 遅れ)` である。 | パターンに書いた値と等しい。 |
| ラウドネス | 各ステムとステムの合算に `ffmpeg -af ebur128=peak=true` をかける。 | 合算が -1 dBFS を超えず、トラックの大小が意図したバランスと一致する。 |
| クリップ | 合算で 0 dBFS を超えるサンプルを数える。 | 0 個。 |
| 無音 | 開始から最後の発までの間で、-60 dB を下回る 100 ms の窓を数える。 | 0 個。 |
| スペクトルのバランス | 各ステムの 30 Hz から 16 kHz までのオクターブ帯域ごとのエネルギーを見る。 | キックは 250 Hz 未満が主、リムとクラップは中域、ハットは 4 kHz 以上が主。 |
| キックの高さ | 長時間平均のスペクトルで、35〜140 Hz の最も強いピークを取る。 | リファレンスがあれば、それに近い。 |

ほかに指定がないときの意図したバランスは、キックを基準にした統合ラウドネスで、バックビートが 3 dB 下、クラップが 6 dB 下、クローズドとオープンのハットが 8 dB 下である。バランスを決めたあとは、ステムの合算でヘッドルームを確かめる。
