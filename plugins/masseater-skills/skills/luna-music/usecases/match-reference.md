# パターンをリファレンス曲に寄せる

1. リファレンスは PC 上で `yt-dlp` でダウンロードし（クラウドからは YouTube に届かない）、クラウドに送る。音声（`-x --audio-format wav`）と動画の両方を取る。
2. 先に動画を見る。解説動画には DAW のノートエディターが映っていることが多い。`ffmpeg` でフレームを抜き、ノートエディターを切り出して拡大し、画面からテンポと音の位置を読む。グリッド上の印は正確なので、密なミックスを解析するより信頼できる。
3. テンポは、オンセット強度の自己相関で音声から推定し、画面に出ているテンポと突き合わせる。オンセットに 16 分音符のグリッドを当てはめる。
4. フルミックスのオンセット検出は信用しない。ボーカル、コード、ベースが偽のオンセットを足し、ハーモニックとパーカッシブの分離でも減らせるだけである。ドラムだけの区間か動画を使い、各パラメーターをどの根拠から得たかを明記する。
5. 音色は、同じ種類の区間のオクターブ帯域ごとのエネルギーで比べる。見るのは、キックの最も低いピークの高さ、60〜250 Hz の割合、ハットの明るさである。サンプルをリファレンスに寄せ、たとえばキックは `asetrate` でピッチを上げ、もう一度測る。
6. [`make-pattern`](make-pattern.md) でパターンを組み直し、[`verify-audio`](verify-audio.md) で検証してから、リファレンスの値と結果の値を並べて報告する。
