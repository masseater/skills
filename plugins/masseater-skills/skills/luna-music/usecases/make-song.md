# 曲を組む

1. 曲の構成を小節ごとのプランにする。UK ガレージの例は 138 BPM で 32 小節とし、イントロ 0〜3、ヴァース 4〜11、コーラス 12〜19、ブレイク 20〜23、ファイナル 24〜31 に分けた。ドラムは [`make-pattern`](make-pattern.md) の手順で、プランどおりにセクションごとのパターンを並べる。
2. ベース、コード、パッドは Polymax のトラックとして足す（[`luna-facts`](../references/luna-facts.md)）。コードの進行は 2 小節ごとに替え、ベースはルート、スタブは 4 音、パッドは同じ和音を 1 オクターブ上げて 2 小節の長い音にする。
3. 使うプリセットを決める前に、候補ごとに単音（ベース）か和音（コード）を置き、そこだけをバウンスして測る。ベースは最強のピークの周波数で鳴る音域を、コードは構成音に乗るエネルギーの割合を見る。音域がずれたプリセットは、書く音高をオクターブ単位でずらして合わせる。
4. 32 小節を書き出し、トラックごとに ebur128 で測る。キックを基準にして、ベースは約 −2 dB、スタブは約 −6 dB、パッドは約 −12 dB に、トラックの `gain.real` で合わせる。合わせたあとにもう一度書き出して、狙った値になったことを確かめる。
5. 全ステムを足した波形のピークが −1 dBFS 以下になるまで、全トラックのゲインを同じだけ下げる。UK ガレージの例では −1.5 dB で −1.2 dBFS になった。
6. 検査は [`verify-audio`](verify-audio.md) に従う。曲では次を加える。ベースとコードの音高をステムのスペクトルで期待した音と比べる（2 小節ごとの和音の替わり目で）。足した波形のスペクトログラムを画像にして読み（`ffmpeg -i sum.wav -lavfi "showspectrumpic=s=1600x512:legend=1:scale=log:fscale=log:stop=12000" out.png`）、構成（ブレイクでベースが抜ける、コーラスでコードが入るなど）がプランと合っているか見る。
