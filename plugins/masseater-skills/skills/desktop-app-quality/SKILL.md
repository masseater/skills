# desktop-app-quality

## この skill が必要な理由と達成したい状態

この skill が必要な理由は、デスクトップアプリを開発する AI は機能が動作するかを確認してそこで切り上げるのに対し、ユーザーは基本機能でアプリを判断することにある。基本機能の不具合に関する不満は、新機能の要望の約 6 倍にのぼる。この乖離は、WebView 内でウェブ技術を用いて画面が動作していることに起因する。リロードや指の形のカーソル、ブラウザの右クリックメニューといったブラウザの挙動は、誰かが削除しない限り残る。また、日本語入力や保存、ウィンドウ処理の不具合は、機能テストでは触れられない形で発生する。

この skill で達成したい状態は、masseater が作るどのデスクトップアプリも、出荷する各 OS 上でそのOS向けに開発されたアプリのように動作し、ユーザーが作業を失ったり待たされたりすることが決してないことである。

## 規則

- デスクトップアプリを設計、開発、またはレビューする際は、[基準](references/criteria.md)のうち当てはまるすべての基準を確認し、それらを満たす。各基準は、ユーザーからの苦情や OS のガイドライン、あるいは定評のあるアプリの挙動に基づいているため、満たさない基準は苦情になる。
- 出荷する各 OS の実行中のアプリで確認して初めて、基準を満たしていると判定する。コードを読むだけでは WebView や OS の挙動が見えず、基準が崩れるのはそこである。
- 基準の確認方法や、Tauri がネイティブコードなしではできないことは、[背景](references/background.md)を読む。
- これらの基準は 2026-11-14 時点の調査に基づいている。特定のバージョンに関する事実に依拠する前に、最新のリリースノートを確認する。
