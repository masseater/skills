# 基準の背景

## 17. 最近のOSの変更 (2026-08～2026-11)

表には、ユーザーが目にする内容と、Tauriアプリに求められる機能が記載されている。

### macOS 27 (2026-09-14; 10-26に27.2, 11-09に27.2.1, 11-03に27.3 beta 1)

出典は[macOS 27のリリースノート](https://developer.apple.com/documentation/macos-release-notes/macos-27-release-notes)、[27.2ノート](https://developer.apple.com/documentation/macos-release-notes/macos-27_2-release-notes)、および[Developer News](https://developer.apple.com/news/)である。

| 変化 | 利用者に起きること | Tauri で要ること |
| --- | --- | --- |
| Apple siliconのみ。Rosettaは27で終了し、Intelソフトウェアは28では動作しない。27.2以降、アップグレードしてもRosettaは削除されなくなった | Intelアプリは「macOS 28では動作しない」と表示される | arm64 かユニバーサルビルドで出す。x86専用の同梱プログラムを確認。`hostArchitecture`のない.pkgはarm64として動作する |
| 旧開発者IDサブCAの有効期限は2027-02-01まで | 旧.pkgファイルのインストール停止 | G2証明書による再署名および再公証 |
| 他の開発者のアプリデータはデフォルトで拒否される。XProtectはブラウザプロファイルや類似のデータを保護する。アプリはTCCデータベースを直接読み込めなくなる | インポート機能はサイレントに失敗し、ユーザーは手動でアクセス権を付与する必要がある | EPERMを検出し、ユーザーを設定へ案内する |
| フルディスクアクセスの付与を困難にする計画を発表（日程未定） | 警告が増える形での付与フローを想定 | フルディスクアクセスに依存しない |
| ユーザーはローカルネットワークの権限を削除し、再申請できる (27.2) | アプリの実行中に権限を取り消すことができる | 取り消し処理を行う |
| メニューアイコンが非表示になる | アプリメニューからアイコンが消える | 27 SDK でビルドする場合は `preferredImageVisibility` を使用する |
| オープンパネルと保存パネルはウィンドウメニューから移動できる。ジェスチャー認識機能はデフォルトで排他的に使用される | − | − |
| launchd が quarantine 属性を持つ plist ファイルをロードしない | インストール済みの LaunchAgent が動作しない | インストール時に属性を削除する |
| Safari 27 および WKWebView: デフォルトでスクロールアンカーが有効、同一ページ内のナビゲーションでCSPが有効、`data:` へのリダイレクトがブロック、ループバックでセキュアクッキーが許可される。これは macOS 26 および Sequoia でも同様である。 | スクロール位置が変更され、古い JavaScript が動作しなくなる | 画面を再度テストする |
| Siri AI の App Intents（27.3 beta、開発版のみ。App Storeへの提出は2027年春に開始） | まだなし | Swift拡張機能が必要。Webレイヤーからのパスが存在しない |
| Liquid Glassの採用が必要 | macOSでは未確認 | 未確認 |

### Windows 11 26H2 (2026-09-29)

出典：[IT Pro guide](https://techcommunity.microsoft.com/blog/windows-itpro-blog/an-it-pro%e2%80%99s-guide-to-windows-11-version-26h2/4559760)。26H1は新型Arm PC専用の別リリースであり、そのまま26H2へアップグレードすることはできない。

| 変化 | 利用者に起きること | Tauri で要ること |
| --- | --- | --- |
| Smart App Controlは再インストール不要で切り替え可能（2026-04以降） | 導入ユーザーが増え、署名のないソフトウェアがブロックされる | すべてのexe、DLL、サイドカーに署名する |
| 管理者保護は一般提供され、10 月の更新で基準の既定になった | すべての昇格時に Windows Hello が要求される | ユーザーごとにインストールする |
| Windows Update とアプリの更新を連携させるオプトイン方式 | − | − |
| パッケージ未同梱のデスクトップアプリに対するカメラ、マイク、位置情報の権限、およびデフォルトで署名済みコードのみを許可するBaseline Security Mode（Insider でテスト中、時期未定） | ユーザーに権限の確認メッセージが表示され、署名のないアプリは「未署名」または誤った名称で表示される | アプリに署名し、パブリッシャー情報を統一する |
| WebView2は152 から 2 週間ごとのリリースになり、Beta検証期間は約21日である（[アナウンス](https://github.com/MicrosoftEdge/WebView2Announcements/issues/137)） | 回帰現象の発生が早まる | Edge BetaおよびDevでCIを実行する。固定版は2倍の頻度で差し替える必要がある |
| Windows 上の MCP は依然としてプレリリース段階にある。Microsoft Execution Containers が一般提供開始された ([2026-10-07](https://blogs.windows.com/windowsdeveloper/2026/10/07/microsoft-execution-containers-policy-driven-containment-for-ai-agents/)) | − | OS に MCP コネクタを公開するにはパッケージ ID（MSIX または MCPB）が必要 |
| 2026-10-22 付 Microsoft Store ポリシー 7.20 | − | 第1章 |

## 19. 作り手が品質を確かめる方法

ユーザーには見えないが、ここまでの体験を保つための手段である。

| 手段 | 現状 |
| --- | --- |
| 実際のアプリでのE2Eテスト | TauriはWebdriverIOの`@wdio/tauri-service`を正式に推奨している。デフォルトの組み込みモードではWebDriverサーバーがアプリ内に配置されるため、macOSでも動作する（[Tauri](https://v2.tauri.app/develop/tests/webdriver/), 2026-06-29）。`tauri-driver`単体ではWindowsとLinuxのみに対応している。これはAppleがWKWebView用のドライバーを同梱していないためである。PlaywrightはCDP経由でWebView2に接続することで、Windowsでのみ動作する（[Playwright](https://playwright.dev/docs/webview2)） |
| 画面のユニットテスト | `@tauri-apps/api/mocks` の `mockIPC` と `mockWindows` |
| 視覚的な回帰 | OSによってレンダリングやフォントが異なるため、OSごとの参照画像を保持する |
| IME | CDPの`Input.imeSetComposition`を通じて、WebView2のみがコンポジションを駆動できる。WKWebViewおよびWebKitGTKは手動でテストする必要がある |
| アクセシビリティ | Windows は CI における自動チェックと、重大なリグレッション発生時のリリース停止を推奨している |
| 擬似ローカライズ | qps-ploc などを用いて長文や切り捨てを確認する |
| クラッシュやハングの追跡 | `tauri-plugin-sentry`（実験的）は、別のプロセスで受信したJavaScriptエラー、Rustのパニック、およびミニダンプを収集する。SentryのネイティブSDKにおけるハング検出はデフォルトでオフになっている。ベンチマークはモバイルのみであり、クラッシュのないセッションの中央値は99.95%である（[Luciq 2025](https://www.luciq.ai/mobile-app-stability-outlook-2025)）。デスクトップでは、セッションは起動から終了まで継続するため、数値を比較することはできない |
| ログ | 公式ログプラグインがログをローテーションし続ける |
| パフォーマンス | 起動時間、入力遅延、アイドル時のメモリおよびCPUを測定する。macOSではアクティビティモニタの「エネルギー」タブに、WindowsではQoSおよび効率モードに表示される |
| リリース前のWebView | WebView2 BetaおよびDev、WebKitGTK 2.54でCIを実行 |

## 20. Tauri では埋められない穴

2.12.5 の時点では、OSの規約に従うには、独自のネイティブコードまたはサードパーティ製プラグインが必要となる。

- 印刷設定、PDFエクスポートとサイレント印刷（#4917, #12284）、iframeの印刷（#13451）
- ファイルをドラッグして実際のファイルを作成する (#2593)、およびWindowsでファイルドロップとHTML5のドラッグ＆ドロップを併用する (#15138)
- ジャンプリストとDockメニュー (#9916, #14460, #14699)
- Quick Look、Windowsプレビュー、Spotlight、Windows検索への登録
- 共有シート
- Linux上のスクリーンリーダー (WebKitGTK)
- Waylandでのグローバルショートカット（plugins-workspace #3267）、およびLinuxでのトレイクリック
- Waylandでのウィンドウ復元（GTK3 のまま）
- Linuxにおける分数スケーリング (GTK3)
- ステージドロールアウト、デルタアップデート、およびアップデート用チャネル
- シークレットストレージ（公式キーリングプラグインなし、v3でストロングホールドが削除される）
- プロキシのPACおよび認証
- 管理者向けポリシー（ADMXなど）
- 再現可能なビルド (#13612)
- IMEの不具合（Windows #16391 および #15436、macOS #15924、Linux #11412 および wry #1724）
- window-state プラグインのバグ (#3289, #3521, #3474, #3350)
- NSIS の更新が途中で止まる (#16277)
Tauri 3.0 (alpha.6, 2026-11-06) では、アプリが Chromium をバンドルした CEF ランタイムを選択できるようになる。これにより WebView 間の差異は解消されるが、バンドルサイズは数百 MB 増加する ([移行ガイド](https://v3.tauri.app/start/migrate/from-tauri-2/))。
