# access

ページと API ごとに誰が見られるかを確かめる。閉じたつもりの URL が開いていると、気づかないまま中身が漏れる。基準は [OWASP ASVS](https://owasp.org/www-project-application-security-verification-standard/) の認証とアクセス制御の章に従う。

| 確かめること | 今の状態の確かめ方 | 満たす状態 |
| --- | --- | --- |
| ページと API ごとの公開範囲 | ルーティングの定義と認証の設定から、全ページと全 API を、公開・ログインした人・本人だけに分けた一覧を作る | 全ページと全 API が、どれかに分けてある |
| 非公開のものが閉じているか | 本番の非公開の URL と、プラットフォームが既定で発行する URL に、ログインせずにリクエストする | 中身が返らない |
| API ごとの権限の検査 | 各 API のハンドラーで、呼び出し元の権限を確かめる処理を探す。ログインしていない呼び出しと、他人の権限での呼び出しのテストを探す | すべての API が権限を確かめ、そのテストがある |

既定で発行される URL を確かめるのは、独自ドメインの前段にだけ認証を置くと、既定の URL から素通りになるからである。
