# publishing

外に出しているものと、その片づけ方を確かめる。一覧に無い公開先は、直されず、消されずに残る。

| 確かめること | 今の状態の確かめ方 | 満たす状態 |
| --- | --- | --- |
| 公開しているもの | README の公開先の一覧と、インフラの定義にある外から到達できる URL、DNS、パッケージの公開先を見比べる | 外から到達できる URL と公開したパッケージが、すべて一覧にある |
| URL の変更 | 移動したページのリダイレクトの設定を探す | 古い URL から新しい URL へ移る |
| 終わらせ方 | インフラの定義から作ったリソースの一覧を作り、消す手順の記述と見比べる | 消す手順が書いてあり、DNS、認証の設定、公開先の一覧まで含めて、作ったリソースをすべて覆う |
