# accessibility

支援技術やキーボードで使えるかを確かめる。マウスと画面で使う開発者には、使えない人がいることが見えない。基準は [WCAG 2.2](https://www.w3.org/TR/WCAG22/) の AA に従う。

| 確かめること | 今の状態の確かめ方 | 満たす状態 |
| --- | --- | --- |
| 機械で見つかる違反 | 本番の各ページに、Lighthouse のアクセシビリティ監査か axe を掛ける | 違反が無い |
| キーボードだけでの操作 | 主な操作の流れを、キーボードだけでたどる | すべての操作ができ、フォーカスの位置が見える |

機械の監査は違反の一部しか見つけないので、キーボードでの操作も確かめる。
