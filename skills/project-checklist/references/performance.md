# performance

ページと API の速さを測って確かめる。開発者の手元の環境と回線では、遅さに気づかない。指標は [Web Vitals](https://web.dev/articles/vitals) に従う。

| 確かめること | 今の状態の確かめ方 | 満たす状態 |
| --- | --- | --- |
| LCP・INP・CLS | 本番の各ページの読み込みと、ページ内のリンクを押した遷移を、Lighthouse の user flow で複数回測る | 各ステップの中央値で、Lighthouse の合格点（0.9）に届いている |
| FCP・TTFB・TBT | 同じ計測の結果を見る | 値が記録されている |
| サーバーの応答時間 | 本番のスパンかログから、API ごとの p95 を出す | 要件の時間に収まっている |

複数回測って中央値で判定するのは、Lighthouse の値が計測する機械の負荷でぶれるからである。
