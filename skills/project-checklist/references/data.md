# data

データをどこに置き、どう変えるかを確かめる。正本が 2 か所にあると食い違い、スキーマを手で変えると本番と定義がずれる。考え方は [The Twelve-Factor App](https://12factor.net/) の backing services と admin processes に従う。

| 確かめること | 今の状態の確かめ方 | 満たす状態 |
| --- | --- | --- |
| データごとの置き場所 | インフラの定義とスキーマから、データの種類ごとの保存先の一覧を作る | 1 つのデータの正本が 1 か所にある |
| スキーマの変え方 | マイグレーションのファイルと、スキーマとの差分の検査を見る | スキーマはマイグレーションを通してだけ変わり、差分があれば検査が落ちる |
| 閲覧者ごとのデータとキャッシュ | キャッシュのキーと、キャッシュに入れる値を見る | 閲覧者ごとに変わる値が、閲覧者をまたぐキャッシュに入らない |
