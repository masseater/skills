# プロジェクトの今の状態を確かめて判定する

プロジェクトの今の状態を、項目ごとに確かめて判定する手順である。

1. 対象のリポジトリと、その本番の URL を決める。本番が無いときは、本番で確かめる項目を「未確認」にする
2. 対象の AGENTS.md と CLAUDE.md を読み、項目の満たす状態を上書きする決まりを控える
3. ルーティングの定義から、ページと API の一覧を作る。「各ページ」はこの一覧を指す
4. `references/` の領域を順に、各項目の「今の状態の確かめ方」で確かめる。見たファイル、実行したコマンド、その出力を控える
5. 項目ごとに「領域・項目・今の状態・判定・根拠」の表を出す
6. 「欠け」と「未確認」を、表の後に一覧にする

コマンドの出力は、判定に効く部分を言い換えずに抜き出して控える。判定の根拠になる。
