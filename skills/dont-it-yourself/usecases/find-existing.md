# 既存のものを探す

references/libraries.md に載っていない場面で、使える既存のものを探して選ぶ手順である。

1. Effect のモジュール、リポジトリにすでに入っている依存、npm の順に探す
2. RFC、W3C、ECMA、ISO などの規格や広く使われている形式を扱う処理は、ライブラリがある前提で、規格の名前と番号、形式の名前、扱うデータの名前で npm を検索する
3. 候補が見つかったら、リポジトリの `packages/` や npm の scope にあるパッケージの一覧を直接見て、何が揃っているかを確かめる
4. 候補が複数あれば、今もメンテナンスされていて、型定義があり、依存が少ないものを選ぶ
5. 既存のもので足りない部分だけを書く

検索結果の要約は、パッケージの一部しか挙げないことがある。要約で範囲を決めつけると、揃っているものを無いと判断して自作する。だから手順 3 で一覧を直接見る。
