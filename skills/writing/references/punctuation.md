# 認識の単位を区切る句読点

句読点は、音読の息継ぎや口語の調子のために打つものではない。読み手が文をどの単位で認識し、どの語句を結び付け、どこで意味を確定すべきかを示すために打つ。

- 読点は、役割の異なる領域の境界に打つ
- 句点は、1 つの主張、判断、因果関係が完了した場所に打つ
- 短い修飾句や対比句の直後には、反射的に読点を打たない
- 読点を足しても解釈が複数残るなら、語順や文を組み直す

## 読点

役割の異なる領域とは、条件、理由、対比、列挙、主節のことである。

ひとまとまりの語句を途中で区切ると、読み手は一度で認識できる内容を、分解して組み直すことになる。逆に、役割の異なる領域を区切らずにつなぐと、どの条件や理由がどの結論にかかるかを、読み手に推測させることになる。

```
ユーザーが入力した、値を検証して、問題がなければ、保存する。
→ ユーザーが入力した値を検証し、問題がなければ保存する。
```

「ユーザーが入力した値」は 1 つの認識領域で、分ける理由がない。元の文は、音読の間に機械的に読点を打ったため、単語の並びが分断されている。直した文では、値を検証する処理と、その結果を条件に保存する処理が区切られている。

```
障害が起きた場合にデータを失わないために処理結果を先に保存する。
→ 障害が起きた場合にもデータを失わないよう、処理結果を先に保存する。
```

元の文は、条件、目的、主となる処理が続いていて、読み手が境界を探すことになる。直した文では、目的の領域と処理の領域が分かれている。

## 句点

長くなったから切るのではない。読み手がそこで意味を確定できるかで決める。

- 独立した主張は一文に詰め込まない
- 1 つの因果関係は、読みやすさのためだけに分割しない
- 一文で表せる対比を短い文に割って、重みや余韻を演出しない

「A ではない。B である」のような分割は、意味のうえで独立していないなら、ただの演出である。

## 反射的な読点

学習データの説明文には、「ではなく」の直後に読点を置く文が多い。AI はそこを反射的に区切る。短く構造が明白な文では、その読点に役割がない。それでも打つと、論理関係をいちいち指差す、典型的な AI 文体になる。「〜ではなくて、」「〜よりも、」「〜するために、」「〜の場合は、」も同じである。誤読を防ぐ必要がない限り、短い修飾句や対比句の直後には読点を打たない。

```
形式ではなく、文章が果たしている働きから判断する。
→ 形式ではなく文章が果たしている働きから判断する。
→ 形式ではなく文章の働きで判断する。
```

ただし、「ではなく」の両側が述語を持つ対比は、役割の異なる領域の境界なので、読点を打つ。

```
長くなったから切るのではなく、読者がそこで意味を確定できるかで決める。
```

音読したときの間は、確認の補助にはなるが、基準にはしない。間は話す人によって変わる。文章で認識させるべき意味の関係は、変わらないからである。

読点を足しても複数の解釈が残るなら、句読点で無理に読ませない。語順や文を組み直す。句読点は、書き手が整理した意味の構造を、読み手にも同じ単位で認識させるためのものである。意味の構造そのものを、句読点で後付けすることはできない。
