# 棚卸しして削る

1. 検証を回し、現状が通ることを確かめる。落ちていれば切り分けて先に報告する
2. 検出を回し、未使用、重複、統合の候補を出す
3. 判断が要る候補だけ持ち主に確認し、他は進める
4. 機械が断言できるもの、統合、文書の順に、意味の単位で PR を切って入れる
5. 作業が終わったと思ったら、単体のコンテキストクリーンなサブエージェントに、達成状態を満たしているかを批判的にレビューさせる。渡すのは達成状態と今のリポジトリの状態だけで、差分も作業の経緯も渡さない
6. 満たしていない点があれば完了とせず、修正に戻る。直すたびに 5 のレビューを繰り返す
7. レビューが達成状態を満たすと判断したら完了とする
