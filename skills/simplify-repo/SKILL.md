# simplify-repo

対象は main ブランチ全体。差分だけ、自分が担当した分だけを見ることはしない。経緯、変更履歴、作業者の意図は見てよいが、全体を見る代わりにはしない。

1. まず simplify-reviewer に main 全体をレビューさせる
2. 指摘を作業の一覧にする。採否はすべて自分で判断して進める
3. 機械が断言できるもの、統合、文書の順に意味の単位で PR を入れる
4. 終わったと思ったら再度レビューさせる
5. 満たしていなければ完了とせず直してレビューを繰り返す
