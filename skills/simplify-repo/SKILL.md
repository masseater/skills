# simplify-repo

- 削る候補は fallow 等の機械検出から取る。勘で探さない
- 検査と上限は緩めない。当たったら中身を軽くする
- 分割しすぎたモジュールとパッケージは統合する。常に一緒に変わるもの、片方からしか使われないものが対象
- 統合で公開面が変わったら、利用側も同じ変更で直し切る。止まって知らせない
- 文書には判断だけ残す。利用箇所、ファイルの一覧、実装の写しは書かない
- 削る変更に振る舞いの変更を混ぜない。PR は意味の単位で切る
- 残すか迷ったら「無くなると誰のどの判断が変わるか」で決める。答えが出なければ削る

手順は [`棚卸しして削る`](usecases/simplify.md)。
