# simplify-repo

- 検査と上限は緩めない。当たったら中身を軽くする
- 分割しすぎたモジュールとパッケージは、迷ったら統合する側に倒す
- 統合で公開面が変わったら、利用側も同じ変更で直し切る。止まって知らせない
- 文書には判断だけ残す。利用箇所、ファイルの一覧、実装の写しは書かない
- 残すか迷ったものは「無くなると誰のどの判断が変わるか」で決める。答えが出なければ削る
