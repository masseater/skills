# simplify-repo

対象は PR や変更差分ではなく main ブランチ全体。今の状態しか存在していないという前提で、過去の経緯と変更履歴は見ない。

1. まず simplify-reviewer に main 全体の今の状態をレビューさせる。渡すのは今の状態だけ
2. 指摘を作業の一覧にする。採否はすべて自分で判断して進める
3. 機械が断言できるもの、統合、文書の順に意味の単位で PR を入れる
4. 終わったと思ったら再度レビューさせる
5. 満たしていなければ完了とせず直してレビューを繰り返す
